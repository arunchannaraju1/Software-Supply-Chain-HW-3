# Contributing to the Python Rekor Verifier

We enthusiastically welcome contributions to this project! Whether you’re fixing a bug, adding an exciting new feature, or enhancing our documentation, your contributions are invaluable.

## How to Contribute

### Reporting Issues

If you discover a bug or have a suggestion for improvement, don’t hesitate to open an issue on GitHub. Be sure to include as much detail as possible, including:
- A clear and concise title.
- Steps to reliably reproduce the issue.
- The expected behavior compared to the actual behavior.
- Information about your environment (e.g., Python version, operating system).

### Submitting Pull Requests

1. **Fork the repository** and create a new branch from `main`.
2. **Make your changes** in your feature branch.
3. **Write tests** to validate any new functionality.
4. **Ensure your code adheres to style guidelines** and passes all existing tests.
5. **Update the documentation** (e.g., `README.md`) as needed to reflect your changes.
6. **Submit a pull request** to the `main` branch of the original repository.

## Code Style

This project proudly adheres to standard Python style guidelines (PEP 8). We utilize tools like `pylint` and `ruff` to maintain high code quality. Before submitting a pull request, confirm that your code runs through these tools locally to ensure it meets the project's style standards.

## Code of Conduct

This project operates under a Contributor Code of Conduct, and your participation signifies your commitment to its principles. (Feel free to add a `CODE_OF_CONDUCT.md` file if you choose).

Thank you for being a part of this project and contributing your talents!
